# Finance Mini App — SvelteKit Frontend

Telegram Mini App (TMA) for personal finance recording, built with SvelteKit 2, TypeScript, Telegram WebApp SDK, and Chart.js.

## Stack
- SvelteKit (Static adapter SPA)
- TypeScript (Strict mode)
- Chart.js (Lazy loaded)
- Telegram WebApp Native CSS Variables (`--tg-*`)

## Commands
- `npm run dev`: Start local development server with Vite
- `npm run build`: Build static production assets to `/build`
- `npm run check`: Type-check Svelte and TypeScript files
